# 托管 S3.6 发布边界执行清单

仅限测试项目 `vellypyadcxkvqftsbrg`。起点为提交 `061780f375a340399bbda662530b07ea83f0971e` 和运行 `988IxvUI` 的独立闭态。发布、撤回和读回沿用原私有 mTLS/PostgREST/真实 Auth 与 R3 入口。本批不重跑已经安装的迁移、SQL 回滚补证、Session 撤销或 Grant 撤销。

私有 `boundary-plan.json` 冻结两个站点、两个 UID、旧快照 ID、已提交发布与撤回的原 DTO、十个新互异请求 ID 和三个 Proof ID。业务持久增量以独立 TLS 会话读回。

| 顺序 | 请求 ID 字段与版本前置 | 预计增量 |
| --- | --- | --- |
| R14 先开发布 ACL，原发布、撤回各重放 | `replays.publish/withdraw.request_id`，原命令使用历史草稿/发布版本 4/0 和发布前置 1，当前实际 5/2 | 同键重放各得到原始回执，改同键内容各一次获 409，Bob 使用 Alice 原键一次获 403。写入为 0 |
| R13 草稿 CAS、发布 CAS 分别过旧 | `draftCas` 使用 4/2，`publicationCas` 使用 5/1，实际 5/2 | 两次均 409，无请求回执 |
| R13 两个不同键并发发布 | `racingA/racingB` 均使用 5/2、当前快照 | 一成功一 409；发布版本从 2 到 3；快照/回执/历史/审计/pending 各 +1 |
| R10、R14 同快照新键与同键并发 | 两请求同 `sameSnapshot`，使用 5/3 和刚创建的 revision 5 快照 | 同一个 changed=false 回执，回执 +1，其余增量 0 |
| R10 显式旧快照 | `oldSnapshot`，使用 5/3 和已存在的 revision 4 快照 | 发布版本从 3 到 4；回执/历史/审计/pending 各 +1；快照与草稿保持原值 |
| R18–R19 公开负例 | 真实 PG `anon` RPC；Alice 发布版本 4、Bob 未发布，两个测试域名临时 active | 正向只返回旧快照，再独立检查 Bob host、无绑定 host、非法 locale、域名禁用、站点删除状态、owner mirror 缺失；夹具全部回滚 |
| R12 撤回与新键重复撤回 | `withdraw` 使用 4，`repeatWithdraw` 使用 5 | 首次发布版本到 5，回执/历史/审计/pending 各 +1；重复撤回仅回执 +1 |
| 有界收尾 | 正常撤回尚未派发且独立读回完全匹配已确认的版本 3 或 4 时，仅 `cleanupAt3` 或 `cleanupAt4` 可使用一次 | 只撤回本次已知指针；未知、指针漂移或正常撤回已派发时停止额外写入，同键读回后关闭 ACL |

成功时 Alice/Bob 草稿为 5/0、发布版本为 5/0、均未发布。回执/快照/发布历史/文本审计/pending 分别为 14/2/5/10/5。所有历史事件按原字段对账，所有 pending 均为零尝试和零发送。

R05 使用两次 Alice、一次 Bob 真登录及各一个新 Grant。共两条短期代次，Alice/Bob 共用正常代次，另一条专用于第二个 Alice Session。分别验证 Alice 管理 hold、站点软删除状态，分别恢复单行并验证读取恢复。仅撤销新建的单用途代次，永久推进 Bob epoch 0→1。不会回退任一 epoch 或代次。成员完整性要求提交时存在唯一 active owner mirror，因此缺失 mirror 仅在 R19 匿名回滚夹具验证。私有 owner 非成员负例使用 Bob 对 Alice 已有成功键的实际重放。自然 Grant 到期用同一 Alice Session 及同一 read RPC，在正向对照后等真实服务端期限到达，随后以未过期的同一 JWT 验证 403；发布 ACL 会先关闭，独立确认 read RPC 仍可用并再读一次作为对照。最多等 1810 秒，本地服务监督窗口 2380 秒。

以新私有目录冻结合成站点和历史回执。使用 `publication-boundaries.mjs --execute-approved <私有运行目录绝对路径> <TLS 校验 psql 包装器绝对路径>`。阶段失败即停止常规写入，记录每个已派发键。未知写入只用同键读回。收尾复核临时状态恢复、两端业务数据、永久状态行、发布 ACL、公开读取与 Outbox gate，最后停止本地服务。Outbox 后续批次单独授权，领取、发送和状态修改均为 0。
