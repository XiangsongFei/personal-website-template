# S3.7 闭态 L1／Edge 本地安装渲染

闭态渲染器接受受限源清单中两个完整 SQL 流之一。源码 SHA-256 由模块固定。未通过摘要校验的字节在渲染前拒绝，原复核工件保持不变。

| 阶段 | 原 SQL SHA-256 |
| --- | --- |
| L1 | `ac48cc40ae15bdb509039eda028a1a1e85183480193a21bcdc4a3dbb439247c2` |
| Edge | `b9a89487f419ec25bb53d5288e0b258a01cde9a91d864188ff4686d0016ee4f4` |

输入为 `{ lane, stage, source, target }`。空库及旧库的 L1、Edge 各用一组固定 schema、角色前缀、桶和锁。目标信息只接受本地夹具标记、独立只读 PG 系统标识 SHA-256 以及 postmaster 启动时间。源 SQL 的旧目标绑定不进入渲染结果。返回 `{ sql, sha256, sourceSha256, scope }` 供受控离线夹具使用。

事务要求本地 Unix socket、禁用 TCP 监听、确切 PG 17.12 和专用安装角色。事务内校验业务及公开门关闭、Auth 函数摘要、Storage 所有权、现有权限和目标命名空间无碰撞。提交前校验专用角色关闭、权限边收敛、无新桶及对象。模块不创建连接，不持有凭据，无自动执行入口。

SQL 最后一项结果包含本次事务声明的 XID。只有另一条只读连接读到同命名空间的已提交目录 XID、完整闭态与原保护摘要后，才能记录已观察提交。若回执丢失且读回无法确定，保持 UNKNOWN 并停留对账路径。可沿用 `checkL1EdgeCatalogWitness` 对已独立采集的保护快照和 XID 作比较，重放旧渲染不构成恢复。
