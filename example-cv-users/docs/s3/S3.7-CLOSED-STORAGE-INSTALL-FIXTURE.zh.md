# S3.7 闭态 L1／Edge 本地安装渲染

闭态渲染器接受受限源清单中两个完整 SQL 流之一。源码 SHA-256 由模块固定。未通过摘要校验的字节在渲染前拒绝，原复核工件保持不变。

| 阶段 | 原 SQL SHA-256 |
| --- | --- |
| L1 | `ac48cc40ae15bdb509039eda028a1a1e85183480193a21bcdc4a3dbb439247c2` |
| Edge | `b9a89487f419ec25bb53d5288e0b258a01cde9a91d864188ff4686d0016ee4f4` |

输入为 `{ lane, stage, source, target }`。空库及旧库的 L1、Edge 各用一组固定 schema、角色前缀、桶和锁。目标信息只接受本地夹具标记、独立只读 PG 系统标识 SHA-256 以及 postmaster 启动时间。源 SQL 的旧目标绑定不进入渲染结果。返回 `{ sql, sha256, sourceSha256, scope }` 供受控离线夹具使用。

事务要求本地 Unix socket、禁用 TCP 监听、确切 PG 17.12 和专用安装角色。事务内校验业务及公开门关闭、Auth 函数摘要、Storage 所有权、现有权限和目标命名空间无碰撞。提交前校验专用角色关闭、权限边收敛、无新桶及对象。模块不创建连接，不持有凭据，无自动执行入口。

SQL 最后一项结果包含本次事务声明的 XID。只有另一条只读连接读到同命名空间的已提交目录 XID、完整闭态与原保护摘要后，才能记录已观察提交。若回执丢失且读回无法确定，保持 UNKNOWN 并停留对账路径。可沿用 `checkL1EdgeCatalogWitness` 对已独立采集的保护快照和 XID 作比较，重放旧渲染不构成恢复。

## 验证范围

现有冻结双基线夹具在两个全新本地 PG 17.12 集群执行 L1／Edge，核验四个候选事务的 XID、故障回滚、目标守卫、权限闭态、L1 PDF 的原生版本和关联保留。边界为真实本地 PostgreSQL 与合成 Storage 平台。#66 的双 Owner 约束由原独立本地组件覆盖。托管归档、真实平台安装身份和已退场项目不进入执行路径。

## 受限安装入口

`runS37PortableClosedInstall` 接受固定 L1／Edge 原件、四个可用夹具范围中的一个、已核验的集群指纹及新的原请求 UUID。它只向当前账户所有的 0700 目录中的 PostgreSQL Unix socket 建立连接。只读见证与安装使用不同登录，安装事务继续执行原夹具的数据库身份、角色、ACL 和关闭门检查。

调用者须预配私有 `s37_install_guard.receipts`。表包含 `request_key uuid PRIMARY KEY`、`scope text UNIQUE NOT NULL`、`render_sha256 text NOT NULL`、`protection_sha256 text NOT NULL`、`observer_role name NOT NULL`、`installed_xid xid8 NOT NULL`。独立所有者保留控制权，`postgres` 仅获得 schema USAGE 和此表 INSERT。独立 `s37_observer_*` 登录无角色继承或成员关系，仅获得 schema USAGE、此表 SELECT 及检查目标所需的 `pg_control_system()` EXECUTE。真实的平台安装身份不在该合同中。

持久账本在数据库派发前记录键和执行字节摘要。数据库在同一事务内保存原请求、审查后的渲染摘要及 XID。服务器返回的 XID 必须与独立观察的目录 XID、正文记录及已提交状态匹配。恢复进程只读回原请求。若本进程收到事务中语句失败、确认执行连接已退出且独立验收原状态未变，可证明该写入已回滚。若进程失联且库中暂时没有记录，候选保留 UNKNOWN。仅凭空目录无法排除晚到写入。

调用者独立提供已审查的 `readProtection`，以只读方式覆盖目录、RLS、Seal、对象版本、revision、hold、Outbox 与关闭终态，并返回固定保护摘要。`closed` 为该观察器的明确判定。受保护摘要在安装前后都必须匹配。安装器核对其自身专用连接退出、实际角色及账本记录，供应商原件和历史范围保持独立。
