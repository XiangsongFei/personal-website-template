# S3.5 私有 PNG 后段事务适配

该代码切片为 #65 的 Seal、complete、close 提供受限私有 PostgREST 适配。预检使用 #65 同一个计划绑定函数。每次请求重算冻结计划摘要，并绑定原请求键、schema、动作、回执、精确对象键和已提交 Seal XID。客户端只允许三个固定写 RPC 和两个固定独立读回 RPC。没有面向业务请求的新增入口。

- 三种写入执行角色和观察执行角色分别绑定独立 socket。三个写角色可共用原本批准的连接登录，观察登录保持独立。Unix socket 须为私有 0600，并绑定已通过启动检查的数据库指纹、登录角色和执行角色。观察请求用 GET 和专用独立连接，源端证明角色和只读事务状态。即使写入响应成功，仍由 #65 通过独立原键读回确定提交。
- PostgREST 适配只负责 Seal、complete、close 的 lookup 及关闭源端。正常链中 prepare、claim、POST、authorize-verify、Verifier 读回须按阶段显式接入既有独立观察。部署前还要核对实际 Schema、Owner、权限和受信保留证据源。适配器不安装 SQL 或受限角色。
- 本地 PostgreSQL 以同 run 锁、原 Seal 请求和实际已提交 XID 执行后段。关闭将该 run 的写入门封闭，保留原 XID 和对象绑定。未找到事件但关闭尚未证明时保持未知。原键恢复由 #65 账本负责，适配器没有写入自动重派。
- 本地集成使用真实 PG17.12 和 PostgREST16.6，实际运行 #65 入口。此前的 Auth、Storage、prepare/claim 和原生 ACL 仍由合成组件提供。测试 SQL 限一次性无 TCP 的本机夹具，不能替代生产权限或历史托管证据。正式下载 BLOCKED。

运行本机集成时设置绝对路径变量 `S35_TEST_PG17_BIN` 和 `S35_TEST_POSTGREST`，从仓库根目录执行 `node --test example-cv-users/tests/s3/support/private-png-postgrest-integration.mjs`。独立读取模式参考 [PostgREST 16 事务文档](https://docs.postgrest.org/en/v16/references/transactions.html)。
# 本地前段事务联测

隔离夹具通过私有 Unix socket 连接独立的 PostgreSQL 17.12 和 PostgREST 16.6。仅对本地夹具发行者启用原子授权 RPC。已有授权事务回调继续用于其他绑定。

prepare 在一笔事务中写入原键、意图摘要、待发布对象和 XID。claim 核对原 prepare 的同一 XID 后占用一次性上传租约；租约受数据库时钟和资格截止时间约束。夹具以同一把事务锁串行处理领取、撤销、上传、Seal、complete 和范围关闭。独立只读连接从原键和冻结摘要核对对象版本、提交及关闭。

本地联测使用合成 Auth 与 Storage。受限夹具角色消耗租约并提交模拟对象版本和请求回执。真实 PNG 解码、MIME、长度和 SHA-256 校验沿用同一生命周期。跨进程恢复读取原持久账本和独立证据，保留已提交对象版本，拒绝重派和未证明的 complete。

生产资格来源、真实 Auth 会话和原生 Storage 对象证明仍需独立取证。此夹具不安装到托管数据库。

## 原项目资格模型联测

联测在全新私有 Unix socket 的 PostgreSQL 17.12 重放冻结的 M1–M7。M7 仅使用原批准的 17.12 前检字面差额。通过项目已有登记、Grant 和建站 RPC 建立 Owner、SID、两站和真实资格行。PNG 资格读取直接联接原项目的运行门、Owner 状态、Grant、签署代次、已消费 proof、站点、成员及 Session。没有另建授权表。独立的 PNG 命令表只保存冻结请求、材料化 prepare、一次性租约及提交读回。

本地适配采用隔离角色的 SELECT 和精确 RLS 范围，使用现有 M5 配置锁与夹具内资格变更锁。闭态检查独立读回门、Grant 撤销、Auth 行清理、私有登录无密码及无连接。历史过期用例预种过期行，未修改数据库时钟，也未缩短真实签发的 Grant。Recovery 由真实 M7 入口拒绝。

新增 Storage transport 固定项目、桶、键、Worker UID/SID、冻结请求、原生版本、摘要和原 claim XID。create-only POST 不跟随重定向，Verifier 使用单次无缓存读取并要求独立原版本回执后才返回完整正文。调用方必须实现真正的版本读及独立观察。联测使用真实本地事务、真实 PNG 字节解析，以及合成 Auth 与 Storage 回执。没有默认联网客户端、生产入口或部署脚本。

S35_TEST_PG17_BIN=/absolute/path/to/pg17/bin \
