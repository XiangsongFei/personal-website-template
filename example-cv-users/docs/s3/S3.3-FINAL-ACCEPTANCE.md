## Transport repair

Fixed Node HTTP could destroy a connection on local finish before draining peer TLS closure. The
owned one-shot client now uses public half-close APIs and waits for complete HTTP, peer end, local
finish and clean close. Seven isolated TLS fixture cases cover 200, expected 409, delayed closure,
post-body reset, abort, truncation and timeout. A true reset stays UNKNOWN and blocks later effects.
The historical domain-conflict response remains 409 with no DB changes; its missing transport
receipt remains UNKNOWN. Exact historical RST packets and old stderr could not be recovered.

Production Worker/hosted Supabase were not deployed or verified by these local results. S2 is unchanged.

remain NOT RUN. Current public paths returned 404 without leaking either unpublished site; that is
not a claim about a future renderer. Physical HTTP hops are topology counts, not packet captures.
Historical STOP/UNKNOWN/CONSUMED records remain private and immutable.

The delivery integration adds explicit generic server bindings and removes legacy Mock signing from
production modules; its new source is checked offline, not claimed as a second live site/Grant run.
