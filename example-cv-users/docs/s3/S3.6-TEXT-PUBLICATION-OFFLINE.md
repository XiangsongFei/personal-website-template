## 代码与合同对应

- 依据 [S3.2 数据模型](S3.2-DATA-MODEL.md) 的永久状态行、不可变版本/快照、
  独立 publication_revision，以及 [事务合同](TRANSACTIONS-AND-API-CONTRACT.md)
  的幂等、失败不切换、撤回和事务 outbox。
- lib/business/text-publication.mjs 是无 I/O 的事务计划器，仅导入已有
  protocol.mjs 的输入/错误/摘要工具；不导入 S3.5 gate、名额缓存、
  identity、repository 或 Storage 适配器。
- 只实现已有 Introduction 文本聚合子集：schema_version=1、entries 中的
  id/position、zh/en 文本。未知字段、NULL 翻译、NUL 和孤立代理码元均拒绝。翻译缺失与空串不同。
  文本中的 URL/HTML 只作为字面文本保存，不解析、不取文件、不渲染。
- initialTextPublication 只在内存投影已有站点的 revision=0 基线；
  不创建真实用户、站点、状态行或 Migration。
- save_text_draft 的有效变化只追加私有草稿历史、增加 draft_revision；
  不移动公开指针。离线只写 Introduction，站点草稿版本也表示该模块版本；真实读取仍须分别返回
  section_revision 和 draft_revision。每个草稿版本最多一个快照，已发布快照独立复制，所有返回结构深冻结。
- publish_site 检查 expected_draft_revision 和 expected_publication_revision；
  首次发布/切换/显式重发旧快照递增公开版本。相同快照 no-op 不递增。
- unpublish_site 设 unpublished/NULL、递增版本并保留永久状态行和历史；
  已取消再次取消为 no-op。不能删除/重建状态行来重置版本。
- 相同 site/actor/operation/request_id 同摘要返回原结果，发生在 CAS 前；
  异摘要冲突。成功结果与原请求、原版本 basis、审计、历史指针和 outbox 一致。
  本地回执绑定摘要覆盖追加位置、原版本、请求摘要和身份作用域，保持命令摘要独立。
  对有成功回执或审计 effects 的操作重建请求摘要并核对内容、快照来源和版本。
  带审计的 UNKNOWN 也核对历史，但仍保留 UNKNOWN。绑定摘要属于内存投影，
  正式请求 DTO 和现有 SQL 编码保持原样。其保护依赖完整的权威历史，不能认证已整体改写的数据。
  新 SID 不使历史请求变成另一个幂等键；未来适配仍须重新验证当前资格。
- 计划包含同一次事务的草稿/快照、状态指针、幂等结果、成功审计与 outbox
  effects；没有数据库 COMMIT 或“已持久化”声明。外层始终为 OFFLINE_PLAN。
- 只读对账外层为 OFFLINE_RECONCILIATION；无记录/pending/unknown 返回 UNKNOWN，
  不推导为失败、不换 request_id 重试、不自动提升历史结果。
- outbox 只计划 pending；没有 purge、投递器或公开读缓存。失败注入测试只证明
  计划被丢弃时输入对象不变，不证明 PostgreSQL 回滚或分布式提交。

纯函数中的 Owner 比较和 actor UID/SID 是领域归属/审计检查，
**不验证真实 JWT、Session、Grant 或撤销状态**，不能当成获准发布能力。
当前 Worker/app 路由没有导入该计划器，原 service 的 publish capability 仍为 false。

## 依赖与尚未验收

1. 真实写入接线仍需要受限服务端身份、当前 Session/Grant/epoch/generation
   校验、Owner 及 RLS、锁序、CAS、唯一性和同事务提交。
   不可复用有 P1 的旧缓存名额作为实时资格证明。
2. 已安装基础 Schema 明确将 draft/section revision 限为 0，
   publication 也冻结为 unpublished/NULL/revision0。
   新快照表/同站 FK、不可变约束、永久状态行、发布 RPC、outbox 和最小 ACL
   尚未通过新的前向候选接线。本轮**没有生成或执行 Migration**，
   不删除这些闭态约束，不修改 M1–M11。
3. 摘要是本地规范化 DTO 经 JSON.stringify 后 UTF-8 SHA-256。
   M4 revision0 的真实摘要源为 PG jsonb::text：
   20261109104802_s3_create_site_commands.sql:167。
   两种输入字节不同，不能直接互比或把本地值回写历史摘要。
   未来持久化适配须分别按各自编码核验，不能重签旧历史。
4. 本地投影记录是 S3.6 语义子集，不是整个数据库导出，也不能覆盖旧 M4
   create_site 审计/操作行。局部历史一致性可拒绝保留旧快照/审计的版本重置，
   不宣称能够抵抗外部将全部权威历史一并擦除；真实存储须由权限和约束保护。
5. 公开请求的当前 site/domain/publication 门禁、缓存键、outbox 投递、
   当前指针撤回及在途请求边界尚未接线或真实测试。不提供直接快照 URL。
6. 所有资产 ready、附件引用、snapshot_assets、私有转公开、复制、签名 URL
   与 E–G 均继续关闭。没有伪造 ready 或允许型文件 Mock。
