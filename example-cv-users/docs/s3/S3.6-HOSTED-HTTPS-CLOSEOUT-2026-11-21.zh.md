## 实际公开 HTTPS

两站仍未发布时，Alice、Bob 分别以真实 Session 获取 R3 Grant，通过现有 mTLS 私有链路验证各自草稿版本。加载冻结 Worker 和本地 TLS 材料，开启测试公开读取和发布 ACL，再通过固定的两个 loopback HTTPS 监听器，用各自 Host 读取 `/api/text-publication?locale=en`。七次请求均完成可验证的 TLS 1.3 握手、命中原公开处理器、发起一次测试项目匿名 `read_public_text` RPC，并返回 `Cache-Control: no-store`。首次发布前，双站已在开闸时取得两次真实未发布拒绝。

| 阶段 | Alice | Bob |
| --- | --- | --- |
| 两站仍未发布，公开门开启 | 404，匿名 RPC `PT404` | 404，匿名 RPC `PT404` |
| 分别确认发布后立即读取 | 200，发布版本 8，独立草稿 4 快照 | 200，发布版本 3，独立草稿 0 快照 |
| 双站均已发布 | 加读一次，相同响应摘要 | 上一格的 200 已发生于双站均发布时 |
