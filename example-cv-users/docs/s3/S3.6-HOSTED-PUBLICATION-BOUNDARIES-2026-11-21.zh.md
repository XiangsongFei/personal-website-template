## 本轮真实结果

| 用例 | 结果及实证 |
| --- | --- |
| 原键重放和冲突 | 原发布和撤回均返回原回执，即使原 CAS 前置版本已经落后。各自使用同一键但改 DTO 时返回 409。当前合格 Bob 重放 Alice 的原发布键返回 403。独立读回一致。 |
| 发布双 CAS | 草稿单独过旧 4/2 和发布单独过旧 5/1，各在真实 5/2 上返回 409；两键同版本 5/2 并行发布时一成功一 409。成功使发布版本 2→3，只新增一个 revision 5 快照、一条回执、历史、审计和 pending 事件。并发按实际 HTTP 请求及独立持久效果验收。 |
| 同快照新键发布和同键并发 | 两条同时发出的同键请求返回同一份 changed=false 回执。新增恰一条回执，版本、快照、历史、审计和事件均无增量。 |
| 显式旧快照 | 以 5/3 明确选择已经存在的 revision 4 快照，发布版本 3→4。当前草稿仍为 5，两个快照内容和摘要均维持原值。`anon` RPC 正向读到旧快照。 |
| 撤回和重复撤回 | 正常撤回 4→5，永久状态行保留、指针清空。新键重复撤回返回 changed=false，只新增一条回执。 |
| 私有资格失效 | Alice 管理 hold 和软删除站点分别先通过本人正向读取，变更后返回 403，恢复单行后读取恢复。仅撤销本批单用途代次，绑定的 Alice 会话仍通过 Auth、业务返回 403，正常代次 Alice 仍可读。Bob epoch 由 0 推进到 1，原新 Grant 仍未过期且 epoch 为 0，真实 Auth 成功而业务返回 403。已撤销的历史 Session/Grant 继续按历史证据保留。 |
| Grant 自然到期 | PASS。发布 ACL 关闭后，同一已授权 Alice Session 再次读取成功；等候 PostgreSQL 真实 Grant 截止时间后，原 JWT 和原生 Session 仍有效，读取 RPC 仍有 EXECUTE，Grant 未撤销且代次未撤销。独立读回仅 Grant 过期，真实业务入口返回 403。 |
| 匿名公开负例 | 真实 PostgreSQL 中以 `anon` 角色调用安装的公开 RPC。正确 Alice 主机返回 revision 4 历史快照。Bob 未发布主机、合法格式的无绑定主机、非法 locale、禁用域名、删除状态站点、缺失 owner mirror 均返回 `PT404`。读回确认撤销临时变更后正向恢复，夹具完全回滚。公开 SQL 角色层面完成；旧 URL、多余 ID 和 Host/header 路由门仍是 HTTP 入口的隔离夹具缺口。 |

业务最终为 Alice/Bob 草稿与 section revision 5/0、publication_revision 5/0，均未发布、空指针。两份不可变快照来源为草稿 revision 4 和 5。持久记录为 14 条请求回执、5 条发布历史、10 条文本审计、5 条 pending 事件。全部事件仍为零尝试、零 lease generation。未开启 Outbox gate。发布 ACL 关闭，公开读取 gate 在回滚探针结束后关闭。本地 PostgREST 和 mTLS 进程退出，监听端口和 socket 独立复核通过。旧 Alice Session 继续消失，旧 Bob Grant 保持 revoked。资格收尾中保留本批授权记录、单用途代次撤销和 Bob 的 epoch 1。没有新的未决 UNKNOWN。旧状态断言在需要 Bob 新 Grant 的未来批次须按 epoch 1 编排。
