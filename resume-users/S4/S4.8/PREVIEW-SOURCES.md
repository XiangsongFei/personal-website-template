# S4.8 预览来源合同草案

| 显示来源 | 输入和新鲜度 | 可见性和行为 |
| --- | --- | --- |
| 本地未保存草稿 | VerifiedWorkspace 内存表单和 dirty 状态。语言可切换 | 跟随当前表单。灰色指导独立渲染，不能回传到 DTO、历史、快照或 AI 输入 |
| 已保存私有草稿 | 当前 Owner 的服务端规范聚合与 draft revision，按当前 Session 和 Grant 重新读取 | 私有、no-store。独显已保存版本及读取失败状态。保持用户仍在编辑的值 |
| 已发布快照 | 当前公开指针指向的不可变投影，包含 publication revision 和公开 locale | 由已验收的公开入口提供。撤回、未发布或域名失效分别遵循 S3.6 公开读合同 |

纯 mapper 输入应是可辨识的三种来源之一。每种来源须通过已存在的字段和顺序合同再投射到显示模型。合成用例覆盖同一栏目的本地脏值、持久版本和旧公开快照各有不同值，缺失语言、显式空值、切换语言、超长栏目标题以及公开链接白名单。已保存私有草稿需 G-READ/G-SAVE，公开来源需发布和撤回入口对应验收。

模板沿用现有最简模板及 full site preview。预览语言、宽窄屏和显示填写示例属展示设置。S4.6 的栏目标题、导航文案及 Links 属站点内容。主题持久模型需后续合同，当前预览不得自动写入这些字段。

## 后续离线接口准备

- S4.9 私有资产按现有头像、PNG、PDF、历史引用和公开引用区分。资格依赖 S3.5 Grant/Permit、最小 ACL、Verifier 和撤销。文本预览允许无文件时展示现有占位。
- S4.10 读接口候选输入可为本站、分页游标、栏目及事件类型。输出限可见事件、时间、栏目、版本号和安全差异。保留未知提交、已确认空列表和权限不足三种语义。恢复另行执行 G-SAVE。
- S4.12 AI1 改写与 AI2 履历文案建议声明允许字段和目标语言。翻译分别支持 zh→en 和 en→zh。候选 schema 包含字段定位、来源语言、目标语言和建议文本。测试包括空源字段、双向语言、输出校验、超时和放弃。确认采纳后只更新本地字段，由用户后续单独保存或发布。
