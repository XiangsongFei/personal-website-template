新 Worker 合同从 S2 验证当前账户范围，经限定绑定调用私有 PostgREST。原 S3 资格、Owner、当前会话和 RLS 是 SQL 权威。新版只有在隔离模式与显式 Worker 本地绑定同时存在时可接线。候选 01–03 安装合同保持物理闭门 CHECK，普通角色默认没有新增 RPC 的 EXECUTE。文本版本、回执与记录 ID 归属在一个事务内追加。每个栏目有独立 revision 和原键 CAS，借用别站或其他父记录的 ID 被拒绝。旧 S3.6 Introduction 暂保持独立 revision。

未决操作标记只保存作用域哈希及站点、栏目、原键、摘要和基础 revision。刷新后只查不可变原回执，旧回执不得覆盖已读到的新版本。主动退出清除该作用域标记。SQL 查询按当前 UID/SID、站点授权、原键和摘要匹配。安全事件或无结论时保留 UNKNOWN。不同账号或新的 Session 不借用旧标记。关闭或刷新后可核对已提交内容，仍未提交的编辑文本遵循原内存生命周期。

## 本地核验边界

本地 Worker 合成套件比较双语与共享字段，覆盖各新栏目重新登录读取、两用户隔离、重复键、过期 revision、记录归属和默认闭态。浏览器脚本验证丢失回执后的刷新及原键核对、跨栏目未保存内容、记录排序、删除、标题回读和账号隔离。Introduction 有独立 Chrome 原键核对用例。原生 Safari 验证丢失回执、刷新、记录持久回读及账号隔离。S4.8 的保存态和发布态 mapper 另有纯数据测试。

Users TypeScript、生产构建及改动文件 ESLint 通过。Users 230 项通过。S3 回归中 Node 988 项通过、4 项跳过，Python 110 项通过。Chrome、Firefox、Playwright WebKit、原生 Safari 合成回归通过，Chrome 和 Playwright WebKit 的 Version 15 闭态导航回归通过。Mac 未安装 Edge。

候选 SQL 离线解析及人工复核覆盖执行权限、资格锁、CAS、原子追加、回执匹配、RLS 和记录归属。Codex CLI 本地审查的当前模型未获账户目录授权。PostgreSQL 执行、目录签名、真实回滚及权限撤销由下次受控验收确认。

## 综合验收授权范围

现有批准只覆盖 Introduction r02。候选 SQL 01、02、03 只完成离线语法解析和静态审查。新增栏目凭真实 RPC 的读写、RLS、撤权、并发和历史仍为 NOT_RUN。真实补验应分自动受控和用户手动两步。须先通过自动真实综合用例，才提供手动验收网站。

建议一次授权独立本机目标 `s47-all-text-acceptance`，使用新建 Unix socket、空数据目录、GoTrue、PostgREST 和仅回环的 Users Worker。执行前锁定版本、实际数据库身份与候选 01–03 的摘要。先闭态安装及一次回滚演练，再校验私有 PostgREST schema cache、RPC 签名和 ACL。仅在短时合成 Owner 窗口，以准确的目标身份开启私有文本入口、调整可逆物理闩并临时授予指定 SQL 调用角色对应 RPC 的 EXECUTE。S3.5 的 Storage、公开读取、发布、撤回和 Outbox 维持关闭。

建议自动阶段最多两站、四次合成登录、四条短时 Grant、一个短代次、180 个文本业务 HTTP 请求、36 个可能写入的保存入口、16 次原键对账和 40 个独立只读或拒绝观察。先验每个栏目双语读取、写入、重新登录后持久化、排序及删除，再验同键、CAS、回滚、UNKNOWN、错站点／记录、原生角色拒绝、撤权及过期。在总预算内为对账和退场预留额度。用户手动窗口的时间、登录和写入预算须在自动 PASS 后单独冻结。两步均仅本机，新增云端费用 US$0，既有 Docker 和 B07 不参与。

出现权限、执行角色、目标或摘要漂移，或预算不足以安全对账及退场时，立即停止变更。发生不确定提交时停止新增业务写入，用原键、摘要和身份只读核对。关闭后由独立连接核对已提交 revision 和审计、撤销 Grant 与代次、Session 和刷新、恢复物理关闸、移除临时 RPC ACL，并核对进程、端口、socket 和数据目录终态。用户手动用独立测试后台进行双语编辑、排序、删除、刷新、退出及测试账号隔离。真实验收与用户确认全部完成后再集中 GitHub 交付。
