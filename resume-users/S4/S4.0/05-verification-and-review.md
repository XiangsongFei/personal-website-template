## CI 与独立审查

现有规则对指向 `main` 的 PR 运行分类和 `Required PR validation gate`。应用构建、安全审计或数据库作业被分类跳过时，保持 `SKIPPED`。相应能力的验收条件见[依赖矩阵](04-dependencies-and-s3-handoff.md)。

替代版的 Required CI 及独立审查结论以对应 PR 的最终 HEAD 为准。独立记录需要覆盖两项 P2 的关闭情况及新增发现。GitHub 官方审查如果未完成，单独保留其实际状态。
