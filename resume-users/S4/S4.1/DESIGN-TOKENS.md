# UI Design V1 — Design Tokens

日期：2026-11-19。Token集中定义于 `example-cv-users/app/dashboard.css` 的 `.dashboard`，不写入全局:root，不改变现有S2页面。

## 固定颜色与用途

| CSS变量后缀（前缀--dashboard-） | 色值 | 用途 |
| --- | --- | --- |
| brand | #688574 | 少量非文本品牌强调；不作为小字号白字按钮背景 |
| brand-light | #EDF3EE | 当前导航/悬停的极浅背景 |
| brand-dark | #466453 | 选中项文字、主按钮、焦点、轻量AI图标 |
| bg | #FFFFFF | 工作区、侧栏、顶栏 |
| bg-secondary | #FAFAFA | 中性网站未开放提示、轻量悬停 |
| text | #242424 | 主标题、正文、分组和内容名称 |
| muted | #737373 | 次要文字、不可操作栏目、辅助说明 |
| line | #E8E8E8 | 非交互装饰分隔线与弱容器边界 |

颜色不单独表达状态。未开放以文字和aria-disabled区分，采用中性灰；品牌绿色不是“已保存”“已发布”或“成功”证明。未来成功/警告/错误沿各自语义配图标和文字，必要时另定义经审核的语义Token，不把所有标签染绿。细分隔线不承担唯一交互边界。

## 对比度实算

按sRGB相对亮度与WCAG公式计算（四舍五入）：

| 前景 / 背景 | 对比度 | 规则 |
| --- | --- | --- |
| #688574 / #FFFFFF | 4.04:1 | 不满足普通小字号AA，不能用于小字号正文或白字主按钮 |
| #466453 / #FFFFFF | 6.55:1 | 小字号文字及白字主按钮可用 |
| #466453 / #EDF3EE | 5.82:1 | 当前导航可用 |
| #737373 / #FFFFFF | 4.74:1 | 14px正文/12–13px辅助文字可用 |
| #737373 / #FAFAFA | 4.54:1 | 中性提示文字可用，后续不可随意降低opacity |
| #242424 / #FFFFFF | 15.52:1 | 主文字可用 |

使用品牌深色而非主色是已确认规范的可读性要求，不属于更换品牌配色。当前不使用渐变、重阴影、玻璃拟态或大面积绿色。

## 排版、尺寸与间距

| 项目 | V1值 |
| --- | --- |
| 字体 | 继承现有Inter/系统sans-serif栈，不新增远程字体 |
| H1 | 桌面32px，手机30px，600字重，1.25行高 |
| H2 | 20px，600字重，1.4行高 |
| 栏目标题 | 14px，550字重，1.5行高 |
| 正文 | 14–15px，1.6行高 |
| 辅助/分组 | 12–13px，保持可读性，导航条目14px |
| space-1…space-6 | 8 / 16 / 24 / 32 / 40 / 48px |
| 字号变量 | font-title / font-section / font-body / font-body-large / font-caption / font-small = 32 / 20 / 14 / 15 / 13 / 12px；手机title覆写30px |
| 侧栏 | 220px；独立滚动，不缩窄以压英文 |
| 顶栏 | 桌面72px，600px及以下64px |
| 主内容 | 最大1120px，桌面40px内边距，中屏32px，手机16px水平内边距 |
| 圆角/阴影 | 4px；无阴影 |
| 触控/键盘 | 顶栏与主操作至少44px高；可见2px深绿焦点线，3px偏移 |
| 断点 | 1100px内容列调整；800px侧栏改披露导航；600px压缩顶栏/账户区域 |

后续S4.2–S4.12复用同一Token和内容层次。网站公开主题与后台品牌Token是两个概念；未来theme_key/主题选项不可默认为后台换色或已可持久化的能力。用户自己的公开主题仍需独立预览/保存/发布合同。
