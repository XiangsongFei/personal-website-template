# S4 功能覆盖矩阵 — UI Design V1

日期：2026-11-19。本表防止视觉优化遗漏业务范围，不将设计承诺写成已开发。对照来源：S4.0 Commit `ef748340a01fc20b9e23229cd828c729511beeaa` 中 `03-minimum-implementation-plan.md`，以及用户本轮已确认的UI Design V1全文。

S4.0文件明确称十二步为“建议映射”，不是已经找到的逐项正式原规划；本轮仍据此对照，不把建议提升为正式编号批准。最新指令明确补入图片、PDF、主题、AI1、AI2及后续HR边界，以下逐项保留。只实施S4.1视觉优化，不重新规划架构或开发后续步骤。

## 步骤对照

| 原S4.0建议步骤 | 原最小范围 | V1设计覆盖/后续沿用 | 本轮实际状态 |

| S4.11 | 发布、撤回与公开快照 | “预览与发布”；独立确认、版本/Outbox/缓存撤回；发布不等同HR同意 | 全关闭，S3.6真实未验收 |
| S4.12 | AI建议及最终回归 | AI1/AI2字段上下文面板、事实确认、采用仅进dirty表单；最终S2/隔离/隐私/可访问性回归 | 仅规范，无模型/Key/保存权限 |

## 特别覆盖项

| 需求 | 明确保留的位置 | 依赖/边界 |
| --- | --- | --- |
| 双语内容 | S4.3–S4.7编辑；S4.8预览；独立于本次UI语言 | 不自动改另一语言，不把UI切换当内容翻译 |
| 图片/头像 | Profile + S4.9文件媒体 | 精确对象、私有授权、哈希与引用保护；未上传 |
| PDF | S4.9后续受控文件能力 | 独立类型/大小/授权/下载/引用合同，当前不开放 |
| 主题 | S4.8主题预览、S4.6网站设置、S4.11发布前确认的设计交界 | 公开主题不是后台Token；当前无theme_key写入/迁移；具体实施批次需与真实原规划对齐 |
| AI1 | S4.12统一字段上下文与建议面板 | 能力分工未在本轮文本中细分，不自行指定Provider或模型 |
| AI2 | 同一组件语言与采纳/事实确认流程 | 不另造独立聊天主题；不直接保存/发布 |
| Activity Log | S4.10独立入口 | 本站安全投影；不能读旧Owner/Test系统日志 |
| Version History | S4.10独立入口 | 历史读取与恢复分别授权，不自动公开 |
| 发布/撤回 | S4.11独立动作 | 真实草稿/快照版本、Outbox与缓存验收，不用离线模型替代 |
| 最终回归 | S4.12综合收尾，且每步仍需自身回归 | 不把S4.1合成通过当整套S4验收 |
| 求职与隐私 | S8导航预留 | 发布网站不自动入人才库，字段许可/撤回独立 |
| HR招聘 | S9–S12独立工作台 | 可复用Token，不共享普通简历私有权限或混入编辑界面 |
| 长期S13扩展 | 本次Token、可折叠导航与领域组件 | 不据此宣称S13具体功能已定义或实现 |

本轮源码只有Dashboard表现和相关测试改变；S2、服务端保护、no-store、Origin/Host及业务API闭态保留。S3.5 HOLD、S3.6真实业务未验收、PR40审计失败及PR41审查额度限制都没有被本表解除。
