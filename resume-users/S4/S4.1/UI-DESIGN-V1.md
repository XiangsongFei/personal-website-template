# Example CV — UI Design V1

日期：2026-11-19（Asia/Shanghai）。正式方向：**Professional Minimalism + Editorial Layout + Sage Green**。本轮是在S4.1基础Commit `0dd20f7e42316af4504b1cae67e5103488658d7c`上的受限视觉实现，不进入S4.2。

用户本轮粘贴的正式文字规范为直接验收依据；旧CMS以现有源码最终生效样式为视觉参考。没有另行风格选型，也不声称对未随本轮提供的AI Dashboard原图完成像素比对。

## 当前实际实现

- 白色工作区、黑灰文字、细分割线；浅绿色只标识选中导航，深绿色用于真实主操作，AI入口有小型线性图标。
- 220px侧栏、72px桌面顶栏、最大1120px主区；手机顶栏64px。标题32px/手机30px，正文14–15px，辅助12–13px，8px间距体系。
- 四组导航以原生details/summary折叠：工作台；个人简历；工具与发布；账户与设置。英文保持单行，侧栏内容可独立滚动。
- 只有概览、品牌回工作台和S2账户入口可导航。未实现栏目为不可操作文本，没有href、tabIndex或业务请求。统一说明可用范围，取消每项重复状态标签。
- Overview：我的工作台 → 我的网站未开放提示 → 七个弱容器内容栏目 → 一条能力说明 → 账户安全区域及真实“管理账户”按钮。没有虚构网站名、站点数量、语言、更新时间、保存或发布状态。
- 顶栏只保留位置、界面语言、账户入口和窄屏菜单；不显示邮箱、UID或站点标识。退出仍在原S2账户页执行，不新写退出API。

## 导航结构

| 分组 | 条目 | 当前可操作项 |
| --- | --- | --- |
| 工作台 | 概览、我的网站 | 概览 |
| 个人简历 | 个人资料、个人介绍、教育经历、工作经历、项目经历、技能、荣誉奖项、联系与链接 | 无 |
| 工具与发布 | 文件与媒体、AI助手、预览与发布 | 无 |
| 账户与设置 | 求职与隐私、活动记录、版本历史、网站设置、账户与安全 | 账户与安全 → /account |

首版单站点仅保留“我的网站”的布局位置，不创建站点切换器或模拟网站卡片。不可用的普通导航和快捷栏目不显示手形、箭头或按钮外观。折叠分组是纯界面操作，不代表开启业务能力。

## 响应式与交互

桌面保留侧栏；800px及以下改为正常文档流中的导航面板，允许内部滚动，非模态抽屉。移动按钮保留aria-expanded/aria-controls，支持Space/Enter；Escape关闭并返回按钮焦点。原生分组支持Enter/Space折叠。跳至主内容链接与概览导航可实际聚焦main。两语共用同一结构与控件，不重挂载S2表单，不改变未来简历内容语言。

内容栏目桌面三列，中窄屏两列；手机保留可读的两列短栏目和单列账户区域。文本可自然换行，导航不得靠省略、裁剪或缩到小字号解决拥挤。设计不使用动画作为信息传达；尊重prefers-reduced-motion。

## 后续编辑器合同（本轮仅设计）

宽屏编辑区约55%，实时预览约45%；手机采用单栏和视图切换。沿用旧CMS的编辑/排序/预览、共享字段与zh/en独立、多记录增删改排、稳定ID、未保存状态、保存草稿、冲突/错误与对应网站模块预览。布局比例可随可用宽度调整，不把55/45当手机硬约束。

真实保存须服务端持久回执后才更新基线；409保留当前表单；结果不明必须核对原请求，不显示虚假成功。图片/PDF必须经过本站授权及引用保护，不能以公开路径代替权限。当前S4.1没有编辑器、上传器或保存按钮。

## AI1 / AI2、预览及发布合同（本轮仅设计）

AI1和AI2嵌入正在编辑的字段/模块：明确选择内容 → 查看原文/建议/待确认事实 → 采用、修改或放弃。采用仅修改当前未保存表单，再由用户另行保存草稿；公开时再次单独确认发布。AI无写库、保存、发布权限，不做两个脱离CMS的聊天机器人。

AI入口共享鼠尾草绿Token，不引入另一套主题。本轮不定义未给出的AI1/AI2产品分工、不调用模型、不设置Key。未来具体服务与数据范围仍需业务合同。

本地未保存内容、已确认保存的私有草稿、明确发布的公开快照，必须在来源、revision和操作文案上区分。发布不自动加入HR人才库。S8求职隐私和S9–S12 HR权限独立；HR未来可复用Token/组件，但界面不塞入普通简历编辑器。
