# S4-UI 正式交付

用户已在本地浏览器验收第一至第九批及最终 LinkedIn 长网址调整，S4-UI 的视觉设计至此冻结。此提交面向 Users 应用。正式合并、新版本上传、生产流量切换和上线验收各自有独立的审批及运行记录。

## 交付范围

| 区域 | 交付内容 |
| --- | --- |
| 工作台与账户 | 登录默认进入概览，品牌导航返回工作台，固定 Header、分组侧栏和独立滚动。账户与安全使用统一工作台，保留右侧改密面板及 S2 认证和错误反馈。 |
| 编辑器 | 单一标准工作区，双语矩阵和等宽共享字段，横线式短字段、可增长文本与纯白长文，独立记录 ID、增删排序、键盘折叠、底部删除确认和栏目撤销。桌面并排，空间不足时可切换单独编辑或预览。 |
| 草稿和反馈 | 同一有效会话内跨栏目与工作台路径保留内存草稿。双语提醒、无需修改、导航圆点、未保存栏目、撤销和离开保护按实际草稿差异触发。 |
| 网站预览 | 独立预览语言与滚动、章节和字段定位、实时更新、高亮及长标题排版。工作和项目起止日期保持单行。115 个中英及共享字段案例覆盖编辑、投射、撤销。 |
| 联系与链接 | 顶部固定子导航，邮箱和 GitHub 双列，LinkedIn 两种 URL 各占单行，可在字段内横向查看，展示设置维持等宽双列。公开邮箱独立于登录邮箱。 |

## 生产隔离和发布边界

- 正式编辑入口使用空白草稿。完整虚构履历与合成认证由隔离本地构建加载，标准应用路由不接受客户端测试模式参数，正式构建的应用入口沿用 S2 服务端身份校验。
- 未持久化的内容只显示为草稿，保存操作继续禁用。站点读取适配器返回服务暂未接入状态，未连接 S3 业务读写。实际文件、Storage、正式下载、发布、撤回及 AI 不开放。真实外链激活在隔离演示中验证，标准编辑入口沿用既有预览合同。
- 与当前生产发布来源对比时恢复了已有的文件、Storage、图片优化别名与静态路径入口保护，保留相同的缓存闭态。回归在隔离 workerd 检查这些路径先于路由和资源分发得以拒绝。
- S3 保持 `S3_PAUSED_AND_ARCHIVED`，本次变更不包含数据库迁移、托管实验或历史工作区文件。旧 CMS 和 Public 的源码保持原样。
- 发布目标仅为 `example-cv-users` 与 `https://admin.example-cv.com`。合并后按被批准的 main SHA 构建。新版本上传与生产流量切换分别审批。

## 验收范围

Users 类型检查、构建、完整离线回归、依赖审计与变更秘密扫描列入发布检查。浏览器回归涵盖 Chromium、WebKit、中文和英文、桌面与窄屏、字段编辑及会话隔离。原生 Safari、人工读屏、实际生产用户业务操作及真实生产发布快照留待相应授权与环境。正式结果以对应 PR HEAD 的检查和审查记录为准。
