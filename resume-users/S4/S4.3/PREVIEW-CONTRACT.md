# 完整网站预览合同

`FullSitePreview` 消费页面内本地模型、内容语言以及当前模块。不引入公开站点的数据文件、旧 CMS 组件运行链、管理权限或数据适配服务。参考旧 CMS `resume-admin/src/preview/ResumePreviewPanel.tsx` 和公开站的版式关系，使用网站导航、个人资料和头像区、紧随其后的介绍、教育、经历、项目、技能、奖项、联系区及页脚。未编辑章节以空状态按完整网站位置展示。当前实现保留章节层级和阅读顺序，尚无后续模块的已填内容、正式公开主题或上传资源。

网页字段使用 React 文本节点呈现，未启用 HTML 注入、外链、头像 URL 请求或生产内容读取。浏览器验收通过真实表单输入合成 Profile/Introduction，正式路由初始化为空。组件把数据来源标为本地、未保存和未发布。未来确权私有草稿与公开快照须有独立数据源与状态，不能借用本地预览作为事实凭证。

## 工作区宽度和滚动

- 工作区可用内宽达到 875 CSS px 时，编辑和预览按 55/45 列宽显示。可用内宽由原侧栏、原页面边距和浏览器窗口共同决定。当前报告的 1440、1280px 为双栏，1024、900、768、390、320px 为单栏。
- 单栏通过“编辑 / 完整网站预览”选择视图。CSS 保留表单和预览实例。内容语言与右上角的界面语言独立。
- 预览具有自己的垂直滚动所有者。进入 Profile/Introduction 时，按预览内锚点定位。如果当前预览隐藏，则在首次可见布局后定位一次。切回已经定位过的同一模块保留用户的手动滚动位置。
- 编辑或切换语言不会触发定位。预览随字段值重新渲染。靠近文档尾部的章节以容器可滚动范围为边界。
- 站内导航按钮只移动预览滚动容器。表单独立滚动，底部操作栏固定于编辑面板，全站预览可浏览八个章节。

S4.4–S4.6 可沿用工作区、两栏规则、视图切换、保存栏和章节定位。后续工作需给编辑模块增加列表模型、字段、对应预览内容及有实际排序语义的控件。现阶段未将 S3 保存、排序或发布合同引入页面。
