# Awards 字段映射

| 旧值 | S4.5 本地草稿 |
| --- | --- |
| `id`、`position` | 稳定 `clientId`、独立 `position`。正式 ID 的关联留给可信读写适配。 |
| `sourceKey` | 本地草稿不产生，未来映射须保留既有值。 |
| `translations.zh/en.name` | 各自保存，可编辑长名称与换行，以文字列表呈现。 |
| `translations.zh/en.year`，合同中为 `award_translations.year_text` | 各自保存原文，包含空字符串或本地化年份写法。 |

旧 CMS 的共享年份动作会写两份翻译。S4.5 按当前内容语言修改，另一语言原样保留。两边都已填写字段且值不同（包括显式清空）时显示提示，可切换内容语言分别确认。缺失值保持缺失，取消修改恢复整个奖项模块的本地基线。未来保存应保留两份原值，并采用正式的记录和站点授权合同。
