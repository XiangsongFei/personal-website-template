# Project Methods 双语顺序合同

旧 CMS 的紧凑列表和自适应展示提供了视觉参考。S3.2 的 `project_methods` 记录以站点、父项目和内容语言为顺序范围。

| 旧值 | 本地草稿 | 顺序与变更 |
| --- | --- | --- |
| 父项目 `id` | 父 `ProjectDraft.clientId` | 移动父项目时，两种语言的子列表随项目移动。 |
| Method `id` | 独立 `ProjectMethodDraft.clientId` | 添加时产生，编辑和排序沿用同一键。 |
| `position` | 父记录在当前语言下的 `position` | 添加为末项，移动或删除后按零起始重排。 |
| `value` | 原始方法原文 | 空值草稿可继续编辑，预览仅投射有内容的子项。 |

切换内容语言只改变当前显示和写入的列表。父级删除需确认，并一并移除父级下的两份本地列表。子行可单独删除，取消 Projects 模块修改会把项目及方法恢复到本阶段的空草稿基线。每条子行有方法编号和成组按钮，首尾禁用无效移动。

未来真实适配需要服务端可信的 `site_id`、正式父项目 ID、每语言授权和有序写入事务，同时正确处理重试、冲突和已有记录来源。本地 ID 只用于工作区。
