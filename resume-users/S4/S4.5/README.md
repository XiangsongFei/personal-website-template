# S4.5 Projects、Skills、Awards

这三个模块已接入 Dashboard 的统一编辑工作区。表单以条目为单位展开、排序和确认删除，页面底部可撤销当前模块的本地修改。UI 语言和简历内容语言各自独立。右侧仍是完整网站预览，窄屏可以在编辑和完整预览之间切换。

- Projects 分别保存中英文标题、副标题、时间、描述和链接的本地输入。每个项目内的中文 Methods 和英文 Methods 独立增删、编辑和排序。
- Skills 提供五种双语预设和 Custom，可切回原自定义标题，技能原文保留换行和标点。
- Awards 分别编辑中英文名称与年份，保留不同年份并显示提示。预览允许长名称换行。

字段与旧 CMS 对照见 [Projects](PROJECTS-FIELD-MAPPING.md)、[Methods](PROJECT-METHODS-CONTRACT.md)、[Skills](SKILLS-FIELD-MAPPING.md) 和 [Awards](AWARDS-FIELD-MAPPING.md)。[编辑器复用](EDITOR-REUSE.md) 和 [预览合同](PREVIEW-CONTRACT.md) 记录共享行为。[测试与截图](TESTING.md)、[S3 依赖](S3-DEPENDENCIES.md) 和 [交付记录](DELIVERY.md) 记录验证与后续门槛。
