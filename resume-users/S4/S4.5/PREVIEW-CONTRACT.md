# 完整网站预览

预览包含 Profile、Introduction、Education、Experience、Projects、Skills、Awards 和 Contact。三段新内容按活动的内容语言投射并沿用本地列表顺序。空章节显示相应语言提示。Projects 链接以纯文字显示，Skills 保留输入中的换行，Awards 长名称沿用可换行排版。

进入模块时，预览把对应章节对齐到粘性导航栏下。靠近末端的章节可以沿用页尾对齐留白，窄屏首次打开预览时也能定位。编辑字段、排序或切换语言不会主动重设位置。手动仍可浏览其他章节，编辑侧和预览侧各有自己的滚动区。

共享容器宽度达到 875 CSS px 时采用 45% 编辑、55% 预览。较窄时显示原有编辑／完整预览切换。百分比只计算编辑网格，固定 Sidebar 独立占用 220px。页面语言选择和账户入口继续位于原 Header。
