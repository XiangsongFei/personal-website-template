# 公开邮箱与本地预览

公开邮箱初始为空，只有用户在「公开链接」显式输入的地址可进入本地预览。编辑器草稿、表单和预览都没有账户邮箱数据源。S2 登录邮箱继续保留为独立私有身份字段。浏览器以隔离的合成账户登录，验证账户邮箱没有出现在表单或预览中。

邮箱字段接收单个裸地址，检查常见 ASCII 邮箱语法，拒绝 `mailto:` URI、地址列表、显示名和头部参数。预览绘制纯文字。未来真实网站若使用邮件入口，可由经确认的地址生成单一接收人的 `mailto:`，对 URI 中的保留字符正确编码。

GitHub、LinkedIn 和已有项目 URL 共享完整 HTTP(S) 地址的验证。拒绝账号密码、控制字符、协议相对地址与其他协议。用户输入留在本地供修改，只有有效 URL 进入预览。预览显示的是可阅读文字，没有可执行链接或嵌入资源。
