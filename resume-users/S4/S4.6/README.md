# S4.6 联系与链接

在 Dashboard 的「联系与链接」进入统一编辑器，选择「联系栏」「公开链接」或「网站文字」。三个区域各有独立的本地草稿和撤销范围。界面语言和内容语言仍可分别切换。

- 联系栏编辑双语联系标题、可联系状态及各自排序的 Focus 和 Status。
- 公开链接编辑明确填写的公开邮箱、GitHub 和 LinkedIn。LinkedIn 的中英文网址独立保留。
- 网站文字编辑五个公开导航标签、五个栏目标题、项目链接文字、简历 PDF 按钮文案和更新时间标签。
