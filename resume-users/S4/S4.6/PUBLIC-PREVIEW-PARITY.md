# 公开简历的版式对照

依据公开站 `app/page.tsx`、`app/globals.css` 与旧后台 `ResumePreviewPanel.tsx`、`preview.css`、`resumeContentMapper.ts`。上线网址的工具访问失败，本轮以版本化公开源码为视觉参考。

| 元素 | 核实的公开站和旧 CMS | S4.6 原预览差异 |
| --- | --- | --- |
| 网站导航 | 首页独立、五个公开锚点、站点语言按钮，手机导航两排 | 八个等权按钮，使用后台式颜色 |
| Hero | Georgia / 宋体姓名、引言位于按钮上方、带图标细框按钮、独立毕业时间、圆形头像；手机头像在前 | 单独介绍章节、小标题和方形头像、网址文字堆叠 |
| 教育、工作、项目 | 桌面栏目标签、条目和时间各自成列。工作与项目为职责列表。Methods 在项目副标题后 | 共用纵向列表，时间及成绩合并，Methods 样式不同 |
| 技能、奖项 | 桌面技能两列，奖项日期靠右，移动端重排 | 全部共用纵向列表 |
| Contact | 大字可联系文案、两个公开联系方式、三栏页脚、Focus 时间线与 Status 图标；公开站在联系锚点展开补充区 | 复用普通列表 |
| 预览容器 | 旧 CMS 使用 980 CSS px 画布、缩放的粘性导航与滚动区域 | 原 S4 用与后台相似的浅灰容器 |

本地预览采用原公开站的展示层级和 980px 桌面基准，按真正可用的预览宽度等比缩放。较窄面板使用未缩放的手机布局。保留独立滚动，并保留八个草稿模块的定位锚点。外部按钮只显示外观，头像使用本地占位，PDF 保持未开放。联系补充区在本地连续展示，正式模板的交互式数据网络图不复制。
