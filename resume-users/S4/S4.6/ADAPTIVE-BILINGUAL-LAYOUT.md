# 双语自适应字段

中英文在同一字段组下同时呈现。每个语言控制件保留独立标签、HTML ID、React key 和更新路径。共享字段仅出现一次。预览内容语言与后台界面语言各自切换，表单持续展示两种语言。

短字段以输入的实际字体和字距进行 Canvas 测量，再加上输入侧边内距与边框。总容器宽度扣除列距后平分，始终按假设的两列评估。每列至少 136px，重回两列需要至少 144px，文字余量按 8px 和 16px 的不同阈值判断。ResizeObserver 与字体加载触发重测，调整只改变 CSS Grid，不卸载输入。长段落始终上下排列，保留阅读宽度。

项目 Methods 分别有各自的记录 ID、顺序和按钮。两个列表根据可用空间自动排成一列或两列，不要求中英条目一一配对。局部取消、删除确认和未保存提醒仍由原工作区与记录工具管理。
