# 完整预览与排序

FullSitePreview 保留八个章节。两条新章节读取本地状态中当前语言，按编辑列表顺序展示有内容的条目。Education 包含类别、标题、项目/学校、时间、成绩和暑期课程信息。Experience 带组织、职位、时间、地点和保留换行的描述。清空或缺失翻译有准确空状态。合成身份及输入仅见隔离浏览器验收，正式路由初始化为空。

模块进入时，只移动预览容器；若预览隐藏，等待可见再定位一次。Education/Experience 处于短页面尾部时，进入模块时只补齐达到锚点所需滚动空间。手动浏览之后保留位置，同模块文本更新、排序和语言变化不触发自动定位。视图切换继续用 CSS 显隐，保留编辑及预览实例。
