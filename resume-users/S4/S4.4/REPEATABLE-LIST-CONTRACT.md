# 多记录本地合同

1. 新增生成有 `local-` 前缀的随机客户端 ID，以独立 position 记录从 0 开始的序号。同行保有 zh/en 字段。
2. 顺序以列表数组为准。上下移动按 ID 查找，交换相邻项并调整位置。首项和末项的无效方向禁用。React 和预览以 ID 作键，避免把输入关联到错误条目。
3. 添加后展开新记录。每个模块一次展开一条。折叠、切换语言、切换模块及切换编辑/预览不会移除输入。重新进入模块可以重新选择要展开的条目。
4. 删除使用行内明确确认，同时移除该条两种语言内容。保留记录仅关闭确认。实际删除后连续重排 position。
5. 状态保存在当前页面内存。取消只恢复本模块的空白基线。其它模块有修改时继续显示离开提示。刷新或离开丢弃本地内容。
6. 缺失翻译保留为缺失，编辑一种语言时只创建或更新该语言。显式空串不触发语言回退。输入长度守卫属于本地 UI。
7. 真实写入前须由服务端分配正式 ID 并绑定可信站点、权限和版本。当前客户端 position 及临时 ID 属于未保存状态。
